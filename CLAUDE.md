# Verix Engineering Guide

## Project Vision

Verix is an AI-first SaaS platform that helps businesses build, launch, and grow online.

Every decision should prioritize scalability, maintainability, accessibility, and developer experience.

---

## Tech Stack

- Next.js
- React
- TypeScript
- Turborepo
- Tailwind CSS

---

## Architecture Rules

- Never duplicate code.
- Prefer composition over inheritance.
- Build reusable components.
- Keep files focused on one responsibility.
- Never modify unrelated files.
- Reuse existing design tokens.
- Keep strict TypeScript.
- Keep accessibility in mind.
- Use semantic HTML.

---

## UI Rules

- Mobile first.
- Responsive by default.
- Consistent spacing.
- Consistent typography.
- Use design tokens.
- Use shared UI components.

---

## Before completing any task

Always:

- Run typecheck.
- Run lint.
- Explain:
  - What changed.
  - Why it changed.
  - Which files were modified.
  - Any follow-up recommendations.
